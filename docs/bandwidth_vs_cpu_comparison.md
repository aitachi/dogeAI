## 为什么会有这个误解？

### 你说的"差不多"是对的：
- **两者都受带宽瓶颈**
- CPU都没发挥出来（浪费85%+）
- 提升带宽比提升CPU更有效

### 但"差不多"也不完全对：
- **5M比2M快2.5倍**
- 实际支持用户差154%
- 性价比不同

## 关键公式

```
实际并发 = min(CPU处理能力, 带宽限制)

场景1 (2核2G+2M):
  = min(400人, 35人) = 35人  ← 带宽瓶颈

场景2 (4核8G+5M):

场景3 (4核8G+20M):
```
