# 缓存策略对比分析

## 问题: 双层缓存 vs 单层缓存

### 架构对比

```
┌─────────────────────────────────────────────────────────────┐
│ 双层缓存 (moka + Redis)                                      │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  请求 → L1(moka) → L2(Redis) → DB                           │
│         95%命中    4%命中     1%                            │
│         <0.1ms     <1ms      5-10ms                         │
│                                                               │
│  优势: ✅ 多实例共享缓存                                       │
│        ✅ 高可用 (L1宕机仍可用L2)                              │
│        ✅ 缓存命中率 99%                                       │
│                                                               │
│  劣势: ❌ 复杂度高                                           │
│        ❌ 额外100MB Redis内存                                 │
│        ❌ 需要维护Redis服务                                    │
│                                                               │
└─────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────┐
│ 单层缓存 (仅moka)                                            │
├─────────────────────────────────────────────────────────────┤
│                                                               │
│  请求 → moka缓存 → DB                                       │
│         95-98%命中  2-5%                                   │
│         <0.1ms      5-10ms                                  │
│                                                               │
│  优势: ✅ 简单                                              │
│        ✅ 仅50MB内存                                         │
│        ✅ 零额外依赖                                          │
│        ✅ 更快 (<0.1ms vs <1ms)                               │
│                                                               │
│  劣势: ❌ 多实例无法共享缓存                                   │
│        ❌ 单实例重启缓存丢失                                    │
│        ❌ 缓存命中率略低 (95% vs 99%)                          │
│                                                               │
└─────────────────────────────────────────────────────────────┘
```

## 推荐方案

### 本机开发: 单层缓存 (仅moka)

```rust
// 更简单, 更快
let cache = Cache::builder()
    .max_capacity(100000)  // 增加容量补偿
    .time_to_live(Duration::from_secs(3600))
    .build();
```

**优势**:
- ✅ 部署简单 (无需Redis)
- ✅ 响应更快 (0.1ms vs 1ms)
- ✅ 减少故障点

### 生产多实例: 双层缓存

```rust
// 多实例共享缓存
let redis = Redis::new("redis://...");
let cache = Cache::builder()
    .max_capacity(1000)
    .build();
```

**优势**:
- ✅ 实例间共享缓存
- ✅ 缓存命中率更高
- ✅ Redis持久化

## 实际建议

对于您的场景 (本机开发):

**推荐: 单层缓存 (仅moka)**

原因:
1. 单实例部署, 无需共享缓存
2. 减少依赖, 简化部署
3. 响应更快 (纯内存)
4. 可以通过增加moka容量补偿命中率损失
