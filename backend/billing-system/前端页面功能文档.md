## API端点完整列表

### 公开接口

```
GET  /                          → 门户入口
GET  /health                    → 健康检查
GET  /api/health/model          → 模型健康状态
```

### 用户认证接口

```
GET  /api/user/balance          → 获取余额 (需: Authorization header)
GET  /api/user/history          → 获取使用记录 (需: Authorization header)
```

### 聊天接口

```
POST  /v1/chat/completions        → 非流式聊天 (需: Authorization header)
POST  /v1/chat/completions/stream → 流式聊天 (需: Authorization header)
```

### 充值接口

```
POST  /api/recharge/redeem        → 兑换充值码 (需: Authorization header)
POST  /api/recharge/create        → 创建充值码批次
GET  /api/recharge/code/:code    → 充值码统计
GET  /api/recharge/batch/:id     → 批次统计
```

### 管理端接口

```
GET  /api/admin/overview         → 系统概览
GET  /api/admin/users            → 用户列表 (支持 page, limit 参数)
GET  /api/admin/billing          → 计费记录 (支持 page, limit 参数)
GET  /api/admin/recharge/stats   → 充值统计
GET  /api/admin/recharge/batches → 充值批次列表
GET  /api/admin/reconciliation   → 对账记录
GET  /api/admin/scheduler/pending → 待处理记录
```
