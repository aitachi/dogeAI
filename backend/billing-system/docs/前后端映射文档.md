## 定时任务详情

### 对账任务 (scheduler/mod.rs)

```rust
start_reconciliation_task()
  └── reconcile_balances()
      ├── 获取所有活跃用户
      ├── 比较DB余额 vs Redis余额
      ├── 记录差异到 balance_reconciliation 表
      └── 修正Redis缓存（以DB为准）
```

### 死信重试任务

```rust
start_dlq_retry_task()
  └── retry_failed_billing()
      ├── 查询 billing_status='pending' 且超过5分钟的记录
      ├── 更新状态为 'completed'
      └── 记录重试数量
```

### 每日重置任务

```rust
start_daily_reset_task()
  └── reset_daily_points()
      ├── 计算下一个00:00
      ├── 查询有套餐用户
      ├── 重置余额到 daily_points
      └── 记录变更到 balance_changes
```
