```json
POST /api/apply
{
  "email": "user@example.com",
  "username": "testuser",
  "full_name": "Test User"
}
```

**响应**:
```json
{
  "success": true,
  "data": {
    "api_key": "aitachi_xxxxxxxxxxxx",
    "user_id": 123,
    "daily_limit": 100000,
    "balance": 200
  }
}
```
