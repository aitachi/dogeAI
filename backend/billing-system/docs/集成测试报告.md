## 部署指南

1. **环境变量配置**
   ```bash
   DATABASE_URL=postgresql://postgres@localhost:5432/api_gateway
   REDIS_URL=redis://localhost:6379
   GLM_API_KEY=your_glm_api_key
   QWEN_API_KEY=your_qwen_api_key
   ```

2. **数据库迁移**
   ```bash
   psql -U postgres -d api_gateway -f migrations/001_init.sql
   psql -U postgres -d api_gateway -f migrations/002_add_reconciliation.sql
   ```

3. **启动服务**
   ```bash
   cargo run --release
   ```

4. **访问地址**
   - 门户入口: http://localhost:3000/
   - 客户端门户: http://localhost:3000/client.html
   - 管理端驾驶舱: http://localhost:3000/admin.html
