⚡ 快速配置命令

第一步：安装 Git 和 NPM

Windows 安装步骤：

1. 安装 Git：

# 方法1：使用 winget（推荐，Windows 11/10 1709+）
winget install Git.Git --accept-source-agreements --accept-package-agreements

# 方法2：下载安装包
# 访问 https://git-scm.com/download/win 下载并安装
# 安装时选择 "Git from the command line and also from 3rd-party software"

# 验证安装（需要重新打开终端）
git --version

2. 安装 Node.js (包含 npm)：

# 方法1：使用 winget（推荐）
winget install OpenJS.NodeJS.LTS --accept-source-agreements --accept-package-agreements

# 方法2：下载安装包
# 访问 https://nodejs.org/ 下载 LTS 版本并安装

# 验证安装（需要重新打开终端）
node --version
npm --version

3. 安装 Claude Code：

# 全局安装 Claude Code
npm install -g @anthropic-ai/claude-code

# 如果提示权限错误，以管理员身份运行 PowerShell 或 CMD
# 或者在 PowerShell 中运行：
# Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser

# 验证安装
claude --version

4. 配置环境变量：

# 在 PowerShell 中设置（临时，当前会话有效）
$env:ANTHROPIC_API_KEY="你的API密钥"
$env:ANTHROPIC_BASE_URL="https://115.190.62.87/v1/anthropic/proxy"

# 永久设置（添加到系统环境变量）
# 1. 右键"此电脑" -> 属性 -> 高级系统设置 -> 环境变量
# 2. 在"用户变量"中新建：
#    变量名: ANTHROPIC_API_KEY
#    变量值: 你的API密钥
#    变量名: ANTHROPIC_BASE_URL
#    变量值: https://115.190.62.87/v1/anthropic/proxy

5. 创建配置文件：

# 配置文件位置
# %USERPROFILE%\.claude\settings.json

# 在 PowerShell 中创建目录和文件
mkdir -p $env:USERPROFILE\.claude
notepad $env:USERPROFILE\.claude\settings.json

# 粘贴以下内容并保存

macOS 安装步骤：

1. 安装 Homebrew（如果未安装）：

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# 安装完成后，根据提示添加 Homebrew 到 PATH：
# (echo; echo 'eval "$(/opt/homebrew/bin/brew shellenv)"') >> /Users/$USER/.zprofile
# eval "$(/opt/homebrew/bin/brew shellenv)"

2. 安装 Git 和 Node.js：

brew install git node

# 验证安装
git --version
node --version
npm --version

3. 安装 Claude Code：

# 全局安装
npm install -g @anthropic-ai/claude-code

# 如果提示权限错误，配置 npm 全局路径
mkdir -p ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.zshrc
source ~/.zshrc

# 重新安装
npm install -g @anthropic-ai/claude-code

# 验证安装
claude --version

4. 配置环境变量：

# 添加到 ~/.zshrc (macOS Catalina 及以后) 或 ~/.bash_profile
echo 'export ANTHROPIC_API_KEY="你的API密钥"' >> ~/.zshrc
echo 'export ANTHROPIC_BASE_URL="https://115.190.62.87/v1/anthropic/proxy"' >> ~/.zshrc
source ~/.zshrc

Linux 安装步骤：

Ubuntu/Debian：

# 更新包列表
sudo apt update

# 安装基础构建工具（某些 npm 包需要编译）
sudo apt install -y build-essential python3 git curl

# 安装 Node.js 20.x LTS (使用 NodeSource 仓库)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs

# 验证安装
git --version
node --version
npm --version

sudo yum install -y python3 git curl

# 安装 Node.js 20.x LTS
curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
sudo yum install -y nodejs

# 验证安装
git --version
node --version
npm --version

Fedora：

sudo dnf install -y gcc-c++ make python3 git curl

# 安装 Node.js
curl -fsSL https://rpm.nodesource.com/setup_20.x | sudo bash -
sudo dnf install -y nodejs

# 验证安装
git --version

npm --version

Arch Linux：

sudo pacman -S nodejs git python python3 make gcc

node --version
npm --version

第三步：创建配置文件（可选）

如果需要自定义配置，创建 settings.json 文件：

{
  "apiBaseUrl": "https://115.190.62.87/v1/anthropic/proxy"

❓ 常见问题

Q: 如何验证安装成功？

在命令行输入以下命令验证：

claude --version

如果显示版本号，说明安装成功。

Q: 如何查看我的API使用情况？

登录后在"使用记录"标签页可以查看详细的使用记录和计费情况。

Q: 如何充值积分？

在"充值"标签页使用充值码兑换积分。如需充值码请联系管理员。

Q: 连接超时怎么办？

1. 检查网络连接：确保可以访问外网

2. 确认API服务器地址正确：https://115.190.62.87/v1/anthropic/proxy

3. 检查API密钥是否正确

4. 尝试运行检测脚本排查问题

Q: npm install 提示权限错误怎么办？

mkdir -p ~/.npm-global
npm config set prefix '~/.npm-global'
echo 'export PATH=~/.npm-global/bin:$PATH' >> ~/.bashrc
source ~/.bashrc

# 以管理员身份运行 PowerShell 或 CMD
Q: Node.js 版本过低怎么办？

Claude Code 需要 Node.js 18 或更高版本。

升级 Node.js：

  • 访问 nodejs.org 下载最新 LTS 版本
  • 或使用 nvm 安装：nvm install --lts
Q: Windows 找不到 curl 命令怎么办？

Windows 10 1803+ 已内置 curl。如果不可用：

  1. 打开 PowerShell 或 CMD
  2. 使用 PowerShell 的 Invoke-WebRequest 替代
  3. 或从 curl.se 下载 Windows 版本
Q: 如何卸载 Claude Code？

运行以下命令卸载：

npm uninstall -g @anthropic-ai/claude-code
Q: 命令行提示 "command not found: claude"

可能原因：

  1. Claude Code 未安装 - 运行 npm install -g @anthropic-ai/claude-code
  2. npm 全局路径未添加到 PATH - 需要重启终端或手动添加
  3. Windows 可能需要以管理员身份运行
