# Aitachi 计费系统 - 部署修复指南

## 问题诊断

访问 `http://115.190.62.87/` 返回404，可能原因：
1. **服务未启动** - Rust服务未运行
2. **端口配置** - 服务监听端口与nginx代理不一致
3. **nginx配置** - nginx未正确反向代理

---

## 快速修复步骤

### 1. 服务器端操作

```bash
# 1. 进入项目目录
cd /root/aitachi/billing-system

# 2. 确保依赖已安装
cargo build --release

# 3. 启动服务（或使用systemd）
nohup cargo run --release > app.log 2>&1 &

# 或使用 systemd 服务
sudo systemctl restart billing-gateway
sudo systemctl status billing-gateway
```

### 2. 检查服务状态

```bash
# 检查服务是否在监听
netstat -tuln | grep 3000
# 或
ss -tuln | grep 3000

# 检查进程
ps aux | grep billing-gateway
```

### 3. nginx配置示例

```nginx
# /etc/nginx/sites-available/billing-gateway

server {
    listen 80;
    server_name 115.190.62.87;

    # 静态文件
    location /static {
        alias /root/aitachi/billing-system/static;
    }

    # API反向代理
    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # API路径
    location /api/ {
        proxy_pass http://127.0.0.1:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    # 健康检查
    location /health {
        proxy_pass http://127.0.0.1:3000;
        access_log off;
    }
}
```

### 4. 重启nginx

```bash
sudo nginx -t
sudo systemctl reload nginx
```

### 5. 检查数据库连接

```bash
# 检查PostgreSQL
sudo systemctl status postgresql

# 检查Redis
sudo systemctl status redis
```

## Systemd服务配置

创建 `/etc/systemd/system/billing-gateway.service`:

```ini
[Unit]
Description=Aitachi Billing Gateway
After=network.target postgresql.service redis.service

[Service]
Type=simple
User=root
WorkingDirectory=/root/aitachi/billing-system
Environment="RUST_LOG=info"
ExecStart=/root/aitachi/billing-system/target/release/billing-gateway
Restart=on-failure
RestartSec=10

[Install]
WantedBy=multi-user.target
```

启用服务:

```bash
sudo systemctl daemon-reload
sudo systemctl enable billing-gateway
sudo systemctl start billing-gateway
sudo systemctl status billing-gateway
```
